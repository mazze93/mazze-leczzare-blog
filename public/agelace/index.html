I

Four rooms

Every screen below is a real screenshot of the app, of a small world invented for the purpose. A script in the repository takes them, so they can't drift from the software.

Pages

Write as if it were already printed.

Give a phrase its own face and ink. Set small caps, drop caps and marginal notes. Type [[ to name another part of the world; naming something that isn't written yet creates it, as a Question.

Everything saves as you type, into a plain file in your world folder.

Boards

Lay the plot out on a table.

Put pages on an endless board and tie threads between them. Draw with a pen (a stylus's pressure counts), sketch in Excalidraw, drop in a map, or write a timeline that draws itself.

Two windows on the same board merge, character by character.

The Pattern

See what names what.

The whole world as a web: grey strands where one page names another, red where you tied a thread on a board, dashed where pages share a board. Drag a seal to pin it. Every page also shows its own small web at its foot.

The Forge

Cut your own type.

Every face you own in one type case. Pair three of them and see a page of your own world set in them. Then draw an alphabet with a broad edge, a quill or a round nib, press Cast the type, and a working .otf appears in your fonts folder.

II

Try it here, now

The real app, running in your browser tab.

Not a recording and not a mock-up. The sandbox is the same build you'd install. A service worker plays the server, running agelace's own server code against a world that lives in your browser.

  • ◆Nothing you make is sent anywhere. The page talks only to itself.
  • ◆Your work stays in this browser until you press Start over.
  • ◆The Forge really casts: draw a few letters and the font loads in the page.

III

Take it home

You need one free program, Docker Desktop, and nothing else: no accounts, no terminal, no subscriptions. Download the zip, unzip it, double-click start-agelace, and your browser opens on your own world.

The guide walks through it with a picture for every step, including the two places Windows asks you something.

V

What went wrong, and the rule it left

  1. Tests that passed for the wrong reason. A test now has to fail for the reason in its name: break the thing it guards and watch it go red before trusting it.
  2. Library behaviour remembered, not checked. Four libraries behaved differently than recalled. Anything that decides correctness gets probed in the container first.
  3. Writes into folders that aren't ours. agelace promises nothing is destroyed. A write into a folder you also use must prove it owns the file, or refuse. Deletions go to the trash folder.
  4. Modes nobody could see. Anything the app does on its own is visible and reversible where it happens. That's why the sandbox wears a ribbon.
  5. Claims ahead of the evidence. Docs that describe the code are checked against the code. This page follows the same rule, which is why the margin cites commits.
  6. Checks that lived in scratch. If it was worth checking once, it lives in the repository with an exit code, and CI runs it.

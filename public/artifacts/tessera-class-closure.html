Stance

This work is done without pay and without an owner. That is not a complaint and not a virtue signal — it is a material fact about the evidence, and it belongs in the record for one reason: nothing here needed to conclude anything in particular.

A vendor writing this up has a product at the end of it. A researcher has a paper. This had neither, which is why the most quoted line in it is the model admitting its own proof was hollow. The finding, runnable

\b is not a security boundary. It means “a transition between \w and \W”, and the runtimes disagree about \w: Python's is Unicode-aware for str patterns, JavaScript's is ASCII-only. The security semantics were resting on a dialect default.

Honest about the emulation: the left column is not CPython. It approximates Python's Unicode-aware \b using \p{L}\p{N}_ lookarounds. It is here to make the seam visible in a page with no dependencies, not to stand in as evidence. The evidence is the command in §7, which runs the real thing.

The policy that replaced the default, stated in English before either file changed:

Policy — human-readable

Match a security keyword unless it is embedded inside a larger ASCII identifier. Unicode letters adjacent to it do not suppress a detection.

Policy — machine-readable

ASCII_IDENTIFIER_CHAR = "[A-Za-z0-9_]"
LEFT  = "(?<!" + ASCII_IDENTIFIER_CHAR + ")"
RIGHT = "(?!"  + ASCII_IDENTIFIER_CHAR + ")"
bounded(p) = LEFT + "(?:" + p + ")" + RIGHT

03

The method

Class-Closure Threat Response. Its governing principle, and note the two qualifiers doing the work — within a stated scope, and silently:

A security finding is not resolved when the reported payload stops working. It is resolved, within a stated scope, when the failure-producing assumption is replaced by an explicit policy and the system can demonstrate that the class cannot silently recur.
  1. Establish the exploit in the real execution path.Not only in a synthetic unit test. In this case study this was done last, not first — see §4.
  2. Name the violated assumption, not the broken test.Identify the abstraction or default that made the exploit possible.
  3. State the policy.Replace implicit runtime behaviour with human-reviewable semantics. In English, before any code moves.
  4. Repair every implementation of it.Consistently, across every boundary that enforces or represents the policy.
  5. Generate adversarial variants over the transformation space.Test the space, not the known strings.
  6. Encode an invariant.Express the security property in machine-checkable form — here: no Unicode-only mutation may lower assessed risk.
  7. Gate the unsafe primitive, structurally.Not the bug — the primitive. Plus a staleness gate on generated evidence.
  8. Prove behaviour at the enforcement boundary.Including telemetry. A high score from a function is not proof that a hook blocks.
  9. Publish the remaining perimeter.Separate demonstrated closure from what is still open.
The loop is not linear, and this case proves it. Stage 5 fed back into stage 2. The mutation corpus did not merely validate the policy — it surfaced U+FEFF, a different violated assumption needing its own policy statement. A practitioner running 1→9 in order would classify that as “a bug found during validation” and patch it. We nearly did. Generation discovers new members of the class, not just violations of the known one. Draw the edge 5 → 2.

Three principles

Parity is a drift alarm, not a semantic judge. A difference proves disagreement; it does not establish which side is right. U+FEFF is the proof: the reference implementation was the wrong one, and “conform to the reference” would have made it worse.

Generated adversarial corpora are executable policy tests. They expose whole mutation families and make coverage shrinkage detectable.

An enforcement claim requires enforcement-layer evidence. assess() returning 0.88 says nothing about whether the hook stops, logs, and fails safely in its real runtime.

The under-named mechanism

Stage 7 reads like ordinary CI hygiene. Two things inside it are not:

  • A gate against reintroducing the unsafe primitive — \b reappearing fails the build, whatever the tests say.
  • An alarm that fires when a quarantined failure starts passing. Suites assert that things work; almost nothing asserts that a known-broken thing is still broken, so that a silent fix cannot erase the record of the gap.

Both fired for real. When the boundary policy landed, all 11 quarantined divergences converged and the alarm reported each one — “known divergence now AGREES — remove the flag and close the issue.” That was the first time that path had ever run.

§4 The spec, in brief

Full text ships alongside as specs/cognitive-topology-reshape.spec.md (v0.6.0). The load-bearing facts, all source-confirmed:

  • INGRESS-I1 — emit the deterministic interpretation of an explicit interaction, never the raw stream. No unmasked representation crosses the canonicalization boundary.
  • Emission tiering — user ratification → ratification (axiomatic); checked test/artifact → verification (verified); model prose → claim (narrative). Mis-tiering is a defect class.
  • Envelope — POST /api/logs/{logId}/events, Bearer STRATUM_TOKEN, snake_case record body.
  • Idempotency — the deterministic id (digest of the masked emission) is the key; a duplicate id → 409.
  • /tessera — reads GET /api/logs/{logId}/projection?epoch=; it is a fold, never a written file.
  • Status is a fold — status_at(event, epoch); wall-clock ignored; single-parent lineage; fail-closed projection.
  • Memory — ranking defers to ContextSynapse's ForwardPass fold; the Lighthouse is carried and protected, never inferred.
  • Degradation — unconfigured = graceful no-op with notice; configured-but-unavailable = visible integrity failure.
